# Phase 26 Client Portal Documentation

## Route: `/portal`

The Client Portal provides a white-label dashboard for end clients:

- **Executive KPI Cards**: Overall SEO health score, indexing ratio, organic search visibility, and active backlink count.
- **Active Campaigns & Link Acquisition**: Live outreach status and partner publication milestones.
- **Report Downloads**: One-click download access to PDF, CSV, Excel, and ZIP report bundles.
- **Support & Notifications**: System notifications and support ticket management.
