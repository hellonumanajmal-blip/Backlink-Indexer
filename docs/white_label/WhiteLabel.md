# Phase 26 Brand & Customization Manual

## White-Label Branding Customization

Agencies and enterprise clients can customize all portal interfaces and deliverable documents:

- **Primary / Secondary Palette**: Hex color styling applied to buttons, accents, headers, and charts.
- **Typography**: Custom font families for web dashboards and PDF report rendering.
- **Logos**: Light logo, dark logo, email header logo, and favicon.
- **Footers**: Custom legal notices and contact signatures in automated report emails.
