# Monitoring Policies & Verification Schedules

## Supported Policies
- **Hourly**: Critical URLs verified every 60 minutes.
- **Daily**: Standard URLs verified every 24 hours.
- **Weekly**: Archival or low-priority URLs verified every 7 days.
- **Monthly**: Deep archive verification every 30 days.
- **Adaptive**: Dynamically increases check frequency for unindexed or newly updated URLs.
- **Priority Based**: Frequency determined by URL priority score (0-100).
- **Manual**: On-demand user verification.
