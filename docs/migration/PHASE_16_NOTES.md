# Phase 16 Database Migration & Operational Notes

## Alembic Migration Revision
- **Revision ID**: `0002_ai_decision_engine`
- **Down Revision**: `0001_initial_schema`

## Added Database Tables
1. `ai_decision_snapshots`: High-level calculation snapshot summaries and scores.
2. `ai_recommendations`: Actionable suggestions generated by the engine.
3. `ai_risk_evaluations`: Granular factor-level risk score breakdown.
4. `ai_predictions`: Metric forecast objects and confidence levels.
5. `ai_opportunity_scores`: Identified indexing opportunity candidates.
6. `ai_decision_audit_logs`: Audit trail logs of engine executions.

## Execution
Run database upgrade:
```bash
alembic upgrade head
```

## RBAC Permissions Added
- `ai:read`
- `ai:write`
- `ai:recalculate`
