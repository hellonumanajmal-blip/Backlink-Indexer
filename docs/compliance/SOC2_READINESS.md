# SOC 2 Readiness Mapping

| Theme | Platform control |
|-------|------------------|
| Security | RBAC, sessions, hashed tokens, security headers |
| Availability | Probes, HPA, backups, DR runbook |
| Processing integrity | Audit log, webhook signatures, backup HMAC |
| Confidentiality | Tenant isolation, secret redaction in logs |
| Privacy | GDPR map, SCIM disable, soft deletes |

Not a certification — evidence pack for auditors.
