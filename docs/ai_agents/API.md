# AI Agents API Reference

## Base path

`/api/ai`

## Endpoints

- `GET /api/ai/overview`
- `GET /api/ai/agents`
- `POST /api/ai/agents`
- `GET /api/ai/providers`
- `POST /api/ai/providers`
- `GET /api/ai/conversations`
- `POST /api/ai/executions`
- `GET /api/ai/executions`
- `GET /api/ai/prompts`
- `POST /api/ai/prompts`

## Authentication

All endpoints use the shared JWT principal flow and existing RBAC permissions.
