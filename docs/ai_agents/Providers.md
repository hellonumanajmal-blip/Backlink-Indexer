# Provider Support Matrix

The platform is designed around pluggable provider adapters with an OpenAI-compatible contract, allowing enterprise deployments to swap providers without changing workflow logic.

Supported provider families:

- OpenAI
- Anthropic Claude
- Google Gemini
- DeepSeek
- Qwen
- Kimi
- Grok
- OpenRouter
- Ollama
- LM Studio
- Custom OpenAI-compatible endpoints
