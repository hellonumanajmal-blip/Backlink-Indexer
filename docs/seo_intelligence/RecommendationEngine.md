# Recommendation Engine Documentation

## Overview
The `RecommendationEngine` processes competitor benchmarks, gap analysis results, and anchor profile distributions to generate actionable SEO optimization suggestions.

## Recommendation Categories
- **Backlink Acquisition**: Targeted outreach for competitor-only referring domains.
- **Link Recovery**: Automated campaigns for broken or lost referring pages.
- **Anchor Profile Balancing**: Suggestions to prevent exact-match over-optimization penalty risk.
- **Content Refresh**: High-growth URL content updates to maintain indexing authority.
- **Crawlability & Internal Linking**: Recommendations to consolidate duplicate URLs and optimize internal page flow.
